# Gestión de Actividades Comunitarias

Aplicación web para visualizar y dar seguimiento a jornadas, talleres y actividades comunitarias según su estado (**en curso**, **próximas** y **completadas**), permitiendo consultar detalles como fecha, hora, ubicación, número de participantes y registro de evidencias.
